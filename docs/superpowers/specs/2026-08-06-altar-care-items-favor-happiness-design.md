## 高好感陪伴幸福

### 触发条件（同时满足）

1. 实体为女仆，且好感**等级** ≥ 80（`FavorabilityManager` / 本模组扩展等级）  
2. 存在主人玩家，同维度  
3. 与主人距离 ≤ `MaidSpeech.OWNER_SPEECH_RANGE`（**16 格**，与饥饿气泡一致；用已有 `OwnerProximityPolicy`）  

### 效果策略

- 效果：现有 `ModEffects.HAPPINESS`  
- **在条件满足时**：若当前幸福剩余时长 ≤ 刷新阈值（对齐夜雀糖纸：约 **20 tick**），则 `addEffect` 刷新到 **3600 tick（3 分钟）**；参数风格对齐饰品托管效果（ambient / 是否显示粒子可与夜雀一致）  
- **条件不满足时**：**不**调用 `removeEffect`；仅停止刷新；剩余时间自然衰减（含糖/蛋糕获得的幸福）  
- 挂载：女仆服务端 tick（与现有幸福饱食恢复 / 饰品 tick 同层，避免客户端重复）  

### 与夜雀糖纸差异（刻意）

| | 夜雀糖纸 | 陪伴幸福 |
|--|----------|----------|
| 条件 | 玩家装备 | 好感≥80 + 主人 16 格内 |
| 刷新时长 | 6000 | **3600** |
| 条件结束 | clear 本模组提供的夜视 | **不清**幸福 |
