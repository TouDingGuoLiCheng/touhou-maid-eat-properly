## 规格摘要

### 物品

- id：`order_book`；中文「点餐本」；英文「Order Book」
- 仅绑定女仆 TLM 饰品；不进玩家 3 格；不进里程碑 BUFF 池
- 祭坛：`minecraft:paper` + `minecraft:stick` + `minecraft:ink_sac`（轻量 power，对齐送餐盒约 0.2）
- 手持右键空气打开配置 GUI；数据在物品 NBT（`mode` + 已选物品 id 集合）

### 过滤

- 基底池 = 现行 `FoodPool`（全模组 edible − HARMFUL）
- 黑名单：`allows = 不在列表`
- 白名单：`allows = 在列表`
- 默认黑名单 + 空列表 → 全放过
- 过滤结果为空 → 不发起新索要 + 空菜单气泡

### 运行时

- 仅女仆**装备**点餐本时影响索要抽取
- 已有索要因菜单变更不再 `allows` → 立刻重抽并说重抽话术；若池空则清除当前索要并说空菜单话术
- 双层饭盒 / 零食管制等仍用全局 `isPoolItem`（点餐本**不**收紧「什么算池内可交付食物」的完成判定，除非后续另定）

### GUI（本期）

- 必须能用：切换黑/白名单、浏览当前索要池食物、点击选入/取消
- 外观、按钮布局、精美排版：**延期**，不阻塞功能验收
