## C4b 根因与修复方向

**根因**：催眠便签调用 `FoodRequestData.setForgotten(true)` 后，同一/下一 tick `FoodRequestHandler.tryCompleteFromBackpack` 若背包有**任意食物池物品**即走 `completeRequest` → 播放 `formatThanks`（「谢谢主人的 XXX」）。

**期望**：使用后只遗忘当前索要——清除索要状态（或等价静默放弃），**仅**播放催眠话术（`speakToOwnerNow`），不完成、不加好感、不感谢。

**建议改法**（二选一，实现时定稿）：

- **A（推荐）**：催眠成功 → `clearRequest` + `scheduleNext`，不调用 `completeRequest`。
- **B**：保留 GUI「已遗忘/任意食物可完成」语义，但催眠后**跳过**背包自动完成至少 N tick，且不在催眠当 tick 做 complete 扫描。
