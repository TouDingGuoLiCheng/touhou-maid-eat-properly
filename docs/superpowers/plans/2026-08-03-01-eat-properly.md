## 1. 产品目标

扩展车万女仆好感度上限，并加入「好好吃饭」相关玩法：定期索要食物提升好感、饱食度维护、长期饥饿掉好感；3 级后每级增加生命，属性随当前等级升降。

---

## 2. 功能规格（第一版）

### 2.1 好感等级

| 项 | 规格 |
|---|---|
| 上限 | 可配置，默认 **100** |
| 每级经验 | 固定一致（可配置单级所需经验） |
| 1–3 级 | 沿用原版行为/表现（在兼容前提下接入扩展） |
| 3 级以后 | 每升 1 级 **+2 最大生命（1 心）**，其他属性不变 |
| 降级 | 生命加成 **严格按当前等级** 重算（降级撤加成） |
| 掉好感「半级」 | 整数等级 + 经验进度；半级 = 扣除升一级所需经验的一半 |
| 下限 | 好感不低于 **0 级**（进度不低于 0） |
| 关键节点奖励 | 第一版仅预留空配置接口/空表，不做具体奖励内容 |

### 2.2 好感获取

- 保留原版获取途径。
- **新增**：完成一次「索要食物」任务 → **+1 整级好感**（或等价于一整级所需经验，以落地实现为准，验收按「完成一次升一级」）。

### 2.3 索要食物

| 项 | 规格 |
|---|---|
| 触发间隔 | 可配置，默认随机 **3–10 游戏日** 一次 |
| 食物池 | 原版 + 农夫乐事 + 妖怪的归家；软依赖，未安装则自动剔除对应条目 |
| UI | 女仆面板旁新增本模组专属页，显示当前需求食物 |
| 完成条件 | 指定食物出现在女仆**背包**中即完成 |
| 野餐篮 | **不算**完成索要（仅可影响饱食） |
| 未完成提示 | 定期气泡 + 聊天栏；话术模板 3–5 条（含食物名） |
| 完成感谢 | 话术含食物名（模板可配） |
| 聊天可见性 | **仅主人**可见 |

**UI 贴图约定**
- 饱食度条：**使用原版饥饿/饱食贴图**
- 模组专属页签图标：`assets/touhou_maid_eat_properly/textures/gui/green_tea.png`（由 `緑茶.png` 重命名）

### 2.4 饱食度

| 项 | 规格 |
|---|---|
| 上限 | 与玩家一致（20） |
| 每日下降 | 约上限的 **30%**（可配置） |
| 回升 | 吃任意食物，按该食物原版饱食度回升；野餐篮喂食应能维持饱食 |
| 低阈值说话 | 低于阈值时定期触发难过话术（3–5 条模板，可含女仆名） |
| 掉好感 | 低于阈值持续 **N 游戏日**（默认 5，可配）仍无改善 → 每个游戏日扣半级经验 |
| 时间类参数 | 索要间隔、低饱食说话间隔、掉好感宽限期等 **全部可配置** |

### 2.5 配置总表（第一版建议键）

- `maxFavorLevel`（默认 100）
- `expPerLevel`（每级所需经验）
- `hpBonusPerLevelAfter3`（默认 2）
- `requestIntervalDaysMin` / `Max`（默认 3 / 10）
- `satietyDailyDrainRatio`（默认 0.30）
- `satietyLowThreshold`（低阈值，实现时给出合理默认）
- `hungerSpeechInterval`（低饱食说话间隔）
- `favorDecayGraceDays`（默认 5）
- `favorDecayPerDayExp`（默认 = 半级 = `expPerLevel / 2`）
- 话术模板列表（索要 / 感谢 / 饥饿）
- 关键节点空表 `milestones: []`

- 依赖：工程使用本地 `touhoulittlemaid-1.5.3-forge+mc1.20.1.jar`
- 构建：Gradle 可用 **JDK 21** 运行；模组字节码仍目标 **Java 17**（1.20.1 要求）

### 阶段 3：饱食度与掉好感  
- [x] 状态：已完成（2026-07-25）  

**交付**
- 饱食上限 20；每日按比例下降；进食按食物营养回升
- 野餐篮定期喂食可维持饱食（在合理喂食频率下）
- 低阈值说话；宽限期后每日扣半级经验；不低于 0 级

**实现要点**
- 存储：复用 `EntityMaid.getHunger/setHunger`（已同步客户端）；宽限期等记在 `PersistentData` 根 `TouhouMaidEatProperly`
- 日界：`getGameTime() / 24000`；每日结算按 `satietyDailyDrainRatio`（默认 0.30 → 约 6 点）下降
- 进食回升：Mixin `DefaultMaidHomeMeal` / `WorkMeal` / `HealSelfMeal.onMaidEat`，按 `FoodProperties.getNutrition()` 回升；升回阈值以上重置低饱食天数
- 掉好感：连续低饱食天数 > `favorDecayGraceDays`（默认 5）后，每日 `reduceWithoutLevel(favorDecayPerDayExp)`（默认半级 = `expPerLevel/2`）
- GUI：好好吃饭页用原版 `icons.png` 饥饿图标显示饱食条
- 配置：`satiety.*`（日降比例、低阈值、饥饿话术间隔、宽限期、每日扣经验、饥饿话术）

**验收**
- `./gradlew build` 成功
- 不喂食时饱食按配置下降，并出现饥饿话术（需自测）
- 喂食后回升，宽计时重置/改善逻辑符合设计（需自测）
- 持续低饱食超过默认 5 日后，每日进度减少约半级，可跨级掉级并同步生命（需自测）
