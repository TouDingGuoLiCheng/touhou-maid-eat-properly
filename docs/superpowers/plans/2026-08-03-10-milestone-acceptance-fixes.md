## C3 — 公屏窗口按女仆排班

### 规则

- **判定单位**：每只 `EntityMaid` 各自的 `MaidSchedule`（白班 / 夜班 / 全天）。
- **可公屏**：当前活动 **不是睡觉**（TLM `Activity.REST`）。工作 + 休息均可公屏。
- **不可公屏（可延迟类）**：处于睡觉时段 → 气泡仍可立刻；公屏进延迟队列。
- **时间源**：继续用 `level.getDayTime()` + TLM 时分公式（与日程 GUI 一致），**不要**用 `getGameTime()`。

### 推荐实现

1. 新增 `MaidChatWindow`（或扩展 `MaidWorldTime`）：
   - `boolean canPublicChat(EntityMaid maid, long dayTime)`
   - 优先：`maid.getScheduleDetail() != Activity.REST`（与 TLM 当前活动一致）
   - 或按 `maid.getSchedule()` 硬编码与 `ScheduleButton` 相同的区间（见上表），便于单测不依赖实体。
2. `MaidSpeech.speakToOwner` / `tickPendingChat` / `nextDeferredDeliveryTime` 全部改为调用「该女仆」的窗口，删除全局 `08:00–20:00` 常量。
3. 延迟投递：在**该女仆下一非睡觉区间**内随机选一点；多条消息不同 `At`，避免到点爆发。
4. 单测覆盖：白班 06/21/22、夜班 05/06/14/15、全天任意时刻。

### 验收

- [x] 单测：白班 06/21/22、夜班 05/06/14/15、全天任意时刻；延迟投递偏移不碰撞
- [ ] 白班女仆：GUI 显示约 06:00–22:00 时 `/ep request now` **立刻**公屏；22:00 后触发 → 排队到次日非睡觉段，且不整点批量爆发。
- [ ] 夜班女仆：睡觉段 06:00–14:00 内触发 → **不立刻**公屏（可延迟类）；14:00 后或工作段内立刻公屏。
- [ ] 全天女仆：任意时刻立刻公屏。
- [ ] 两只不同排班女仆互不影响（各自窗口）。

## C4 — 道具类话术：立即公屏、永不入队

### 问题

催眠便签等走 `speakToOwner` → 窗外入队，表现为「用了才出现 / 偶发延迟」。

### 规则

| 类型 | 气泡 | 公屏 | 入队 |
|------|------|------|------|
| **道具即时类** | 立刻 | **立刻**（无视睡觉窗口） | **禁止** |
| **可延迟类** | 立刻 | 仅非睡觉窗口；否则入队 | 可以 |

### 道具即时类（本轮明确）

玩家**主动使用本模组道具**触发、且语义为「这一次」的话术：

- 催眠便签成功遗忘（`hypnosisSpeech`）
- 加餐许可触发的新索要话术（若走 `speakToOwner`）
- 其他日后同类「右键道具 → 一次性反馈」默认归此类

**仍为可延迟类**：自然索要、饥饿抱怨、里程碑送礼、周期性催促、放弃索要等非「这一次道具」路径。

### 实现

- 新增 `MaidSpeech.speakToOwnerNow(EntityMaid, String)`（或 `speakToOwner(..., boolean forceImmediate)`）：气泡 + 公屏，**跳过**窗口判断与 `enqueuePendingChat`。
- 催眠便签 / 加餐许可等调用点改走即时 API。
- 普通路径继续走排班窗口（C3）。

### 验收

- [ ] 女仆在睡觉时段：用催眠便签 → **立刻**公屏 + 气泡；队列中**不出现**该条。
- [ ] 同时有可延迟类排队消息时，道具即时话术不跟它们绑在一起延迟。
- [ ] 白班白天用催眠便签：行为与现在「立刻」一致。

## F1 — 索要池剔除负面效果食物

### 问题

`FoodPool.isPoolItem` 只要求 `isEdible()` + 命名空间（minecraft / farmersdelight / youkai），毒马铃薯等会进池。

### 规则

- 食物 `FoodProperties` 带有 **有害** 效果（`MobEffectCategory.HARMFUL`，或等价：中毒、饥饿、凋零等）→ **不得**进入索要池。
- 典型例子：毒马铃薯、腐肉、蜘蛛眼、河豚等（以效果检测为准，不必只硬编码名单；可另加黑名单兜底）。
- `isPoolItem` / `pickRandom` / 催眠「任意池内食物」完成判定共用同一过滤，避免索要与完成不一致。

### 验收

- [x] 单测：`FoodPoolSafety` 识别 HARMFUL 效果类别
- [ ] `/ep request now` 多次：不再出现毒马铃薯等有害食物。
- [ ] 普通食物（面包、苹果、农夫乐事菜等）仍可索要。
- [ ] 已存在的「有害索要」若仍挂在女仆身上：完成/放弃逻辑不崩溃（可选：下次 roll 时自然换掉即可）。
